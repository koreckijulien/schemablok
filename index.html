Atelier schémas-blocs

La simulation démarre à t = 0. Les pas s’arrêtent exactement sur les échelons, les fronts de créneau et les instants d’échantillonnage.

Variables utilisables dans tous les paramètres, une affectation par ligne.

Exemples : m = 1.5, w0 = sqrt(k/m), den = [1 2*z*w0 w0^2]. Commentaires après %.

Traceur

    Glissez un bloc depuis la bibliothèque. Tirez un fil d’une sortie ● vers une entrée ○. Double-cliquez sur un bloc pour régler ses paramètres.
